Main rule is have an unsquished high res one just for fun, then lower its resolution 

## **Resize it so its 140 pixels wide**
then put in foruse
A good way of doing this is through [ImageMagick](https://github.com/ImageMagick/ImageMagick) by running `magick input.png -resize 140x output.png`.
Or you could just use [EzGIF](https://ezgif.com/)

Each image is usually 140 pixels wide and 50 pixels high (the height doesn't have to be exactly 50!)

Go crazy!
