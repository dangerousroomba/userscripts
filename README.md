# Userscripts
Have fun with these userscripts!

Don't be afraid to suggest anything, open issues or send a pull request :)

## Installation
1. Grab a userscript manager like [ViolentMonkey](https://violentmonkey.github.io/) 
2. Open this github repo and open the .user.js of whichever userscript you'd like to install
3. Click "Raw file" on the page viewing the code
4. Press "Install" on the window that appears.
